## Superintendent / district-leader flow
The site now supports a decision path of:
Home → K–12 architecture → evidence of learning → school/district implementation → readiness / professional learning → public resources → conversation.

The For Schools page follows:
Engagement options → staged implementation → readiness assessment → professional learning → practical pilot model / public opportunity brief → what is already built → experience / capability → consultation.

This allows a leader to understand the offer, see evidence, evaluate implementation risk, and decide on a next step without opening protected curriculum.

## Educator flow
The educator-facing path is:
Curriculum → grade-band pathway → exact current learning sequence → workbook preview / sample lesson → instructional cycle → assessment/evidence → implementation guidance → professional learning.

The For Educators page remains focused on practical professional learning, implementation formats, and common teacher questions rather than repeating the entire curriculum site.
